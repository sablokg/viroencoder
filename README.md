# viroencoder

- studies folder contain accumulated literature for the viruses.
- The studies will be updated regularly with the relevant literature.
- virus infecting plants or fungal.
- virus anamoly detection using autoencoder

### Purpose and aim of the cargo
- Building the following for the viruses.
- LSTM sequence based regression for viral infection rate - complete
- Transformer - complete
- Autoencoder based anomaly detection of viral sequences. - complete
